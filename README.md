# LifeLog
Diary + steps + screen time + weather + devotion + income/expense tracker (Python / Kivy).

Build: push to GitHub (branch main). Actions > "Build APK" builds it. If it fails, open the run's
summary page for the error text. Alternative: Actions > "Build APK (Docker alternative)" > Run workflow.
Download the APK from the run's Artifacts (lifelog-apk).
